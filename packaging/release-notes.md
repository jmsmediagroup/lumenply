### First launch

These builds are not yet signed with a paid developer certificate, so the
system asks once before the first launch:

- **macOS**: if it says Apple could not verify Lumenply, open **System Settings ▸
  Privacy & Security**, scroll down and click **Open Anyway** (once).
- **Windows**: if SmartScreen says it protected your PC, click **More info ▸ Run anyway**.
- **Linux**: `chmod +x Lumenply-Linux-x86_64.AppImage` and run it.

The AI features (Select Subject, Object Selection, Remove Background) download
their models the first time you use them, after asking; they then run offline.
On macOS they need an Apple Silicon Mac; Intel Macs get everything else.
